# Web de la Asamblea Tomás Bretón

Web estática de la Asamblea Tomás Bretón (maestras y maestros del colegio): reservas de camisetas, chapas, mochilas y botellas, avisos de «quiero ayudar», información del sorteo de una cesta y del puesto informativo a la entrada y a la salida del colegio. No cobra nada online: cada solicitud llega a una hoja de cálculo de Google y al correo asambleatomasbreton@gmail.com, y la asamblea lo acuerda después con cada persona por correo.

## Estructura
- `index.html` + `assets/` — portada (formulario primero) y textos.
- `privacidad.html` — página de privacidad.
- `apps-script/Code.gs` — backend en Google Apps Script (validación, anti-spam, registro en hoja y correos).

Privado mientras se revisa.
